프론트엔드 개발을 담당하며 사용자 및 관리자 기능을 구현하고,

### 🧪 TraceLab
> Unreal Engine · C++

연구실 탈출을 목표로 하는 추격 AI 게임 프로젝트입니다.

일반적인 게임 AI처럼 플레이어의 위치를 직접 전달받는 대신,  
문 개폐, 보안카드 사용 등의 **게임 내 증거를 기반으로  
AI가 플레이어의 위치를 추론하고 추적하는 시스템**을 구현하고 있습니다.

Unreal Engine의 AI Perception과 C++를 활용해  
수색 → 조사 → 추격으로 이어지는 AI 행동 구조를 설계하고 있습니다.

🔗 [Repository](https://github.com/hannavii/TraceLab)

### 🎙 Voice AI Visual Novel
> Ren'Py · Python · Whisper · OpenAI API

플레이어의 음성을 이용해 캐릭터와 대화할 수 있는  
AI 기반 비주얼 노벨 프로젝트입니다.

플레이어의 음성을 녹음한 뒤 Whisper를 이용해 텍스트로 변환하고,  
입력된 내용과 상황을 분석하여 캐릭터별 AI 대사를 생성하도록 구현했습니다.

음성 입력을 이용한 플레이어 이름 추출과  
캐릭터 호감도 시스템도 함께 구현했습니다.

🔗 [Repository](https://github.com/hannavii/voice-ai-visual-novel)

### 📹 CSEETV
> Python · OpenCV · Computer Vision

야간 CCTV 영상에서 이상 움직임을 감지하는 팀 프로젝트입니다.

**영상처리 파트**를 담당하여 OpenCV 기반 영상 전처리 및  
움직임 검출 파이프라인을 구현했습니다.

CLAHE, Gaussian Filtering, Running Average, Morphology, ROI 등의  
영상처리 기법을 적용하고, 여러 움직임 감지 방식을 비교·평가했습니다.

🔗 [Repository](https://github.com/cseetv/cseetv_ip)
